Autumn 1983

A calculator.
Steve Jobs
had notes.

Chris Espinosa developed the Calculator Desk Accessory for the original Macintosh. Jobs kept rejecting every version Espinosa showed him — the buttons were too thick, the lines too thin, the spacing awkward.

02
Early 1984

The Calculator
Construction
Set.

Espinosa's legendary solution: he built a settings panel that let Jobs tune every single visual parameter himself — button sizes, line widths, padding. Jobs spent an hour tuning it, and ended up choosing values nearly identical to Espinosa's original.

03
24 January 1984

Ships with
the first Mac.
Icon by Kare.

Susan Kare designed the iconic pixel-art desk accessory icon. Andy Hertzfeld implemented the UI in System 1.0. It became an instantly recognizable piece of computer history — now reimagined as a modern native Mac app.

Artwork

Every pixel
is a rectangle.

The artwork is pure SVG vector paths rendered with shape-rendering="crispEdges" — mathematically sharp at any scale from 1× to 4× on Retina displays.

Three authentic variants: rich-black active titlebar, hollow inactive state, and pure high-contrast Monochrome — switchable anytime from settings.

▶ Click to hear the mechanical click
Tactile Feedback

A relay
click.

Synthesized in real time using the Web Audio API — a 40ms shaped noise envelope recreating the physical mechanical snap of 1980s computer keys.

In the Mac app, every keypress plays this sound with sub-millisecond latency. You can toggle sound effects on or off with a single shortcut.

Typography

A font built
for seven
segments.

MacCalculatorDisplay is a bespoke bitmap typeface that accurately replicates the original 7px LCD-style display numerals created by Apple in 1984.

Numbers render right-aligned with authentic pixel gaps, exactly as they appeared on the original Macintosh screen.
