# Classic Calculator — Promotional Website

A modern, dark-themed landing page for [Classic Calculator](https://github.com/19JVJeffery/ClassicCalculator) — a pixel-perfect native macOS recreation of the 1984 Macintosh Calculator Desk Accessory.

**Live site**: [https://19jvjeffery.github.io/ClassicCalculator/](https://19jvjeffery.github.io/ClassicCalculator/)

## Features
- Interactive playable calculator with keyboard support and Web Audio click sounds
- Bento-grid feature showcase
- Pixel-perfect SVG artwork
- History & story section (Jobs, Kare, Hertzfeld)
- Fully responsive · Zero dependencies

## Stack
Plain HTML + CSS + Vanilla JS. No build step. No frameworks. No npm.
